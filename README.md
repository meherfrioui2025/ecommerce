# E-Commerce Platform

A modern e-commerce platform built from scratch with a focus on clean architecture, scalability, maintainability, and real-world software engineering practices.

The project includes a customer-facing web application and a backend system designed to support products, merchants, customers, orders, payments, inventory, and notifications.

## Project Structure

- `frontend/` — Customer-facing web application
- `backend/` — Backend services and API

## Goals

- Build a scalable and maintainable e-commerce platform
- Apply clean architecture and SOLID principles
- Design clear boundaries between business domains
- Implement reliable communication between backend services
- Follow production-oriented development practices
